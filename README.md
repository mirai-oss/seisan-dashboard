# 精算ダッシュボード

業務委託先の精算書を、入力チェック・PDF発行・メール送信・振込管理まで一気通貫で扱うWebダッシュボード。

- **画面**: このリポジトリの `index.html`（GitHub Pagesで配信・Google非依存の静的サイト）
- **データ処理**: Google Apps Script（`gas/SeisanDashboard.gs`）を軽量JSON APIとして利用
- **対象スプレッドシート・各種ID**: コードにはハードコードせず、`設定_外部連携`シートで管理（→ Publicリポジトリでも機密情報が入らない構成）

## なぜこの構成？（GAS単体のHtmlServiceをやめた理由）

以前はGoogle Apps ScriptのHtmlServiceで画面ごと配信していましたが、Google Workspace管理者の「Apps Scriptサービス制限」等により、組織アカウントでログインしたスマホから開けなくなる事象が発生しました。

画面をGitHub Pages（Googleと無関係な普通のWebサイト）にし、データのやり取りだけを軽いfetch(JSON)でGASと行う構成にすることで、この制約を回避しています（売上ダッシュボード [tori-dashboard](https://github.com/mirai-oss/tori-dashboard) と同じ考え方）。

- 画面を開く: 完全に独立、Googleログイン不要
- データ取得・登録: `fetch()` でGASの `/exec` URLをJSON APIとして呼ぶ（POSTを基本とし、失敗時はGETに自動フォールバック）
- ログイン・権限チェックはAPI呼び出し内で行う（GASのHtmlService依存を廃止）

## 主な機能

| 区分 | 機能 |
|---|---|
| 入力 | 明細入力（行ごとにファイル添付・自動リネーム）、明細修正（修正日記録・修正版は【再】付与）、先の月へ一括計上、現金売上の自動取込、定期費目の自動セット |
| 発行 | PDFプレビュー、精算書PDF発行（1ページ・自前生成）、メール送信（その月の添付書類も同封）、再送信（件名・PDF名に【再送信】） |
| 管理 | 法人別の合計振込額・振込先・振込済みチェック、振込完了メール、店舗×月マトリクス、年間推移（売上/振込/N-style収益・CSVダウンロード） |
| 権限 | 本部（全機能）／委託先（担当店舗の閲覧のみ・N-style収益は非表示） |
| 自動 | 毎月1日 定期費目セット、毎月18日 振込期限リマインド |

## ファイル構成

- `index.html` — 画面本体（GitHub Pagesで配信）
- `gas/SeisanDashboard.gs` — GAS側バックエンド（JSON APIのみ。**Apps Scriptに貼り付けるのはこの1ファイルだけ**）
- `gas/SeisanDashboard_コピー用.txt` — 貼り付け用テキスト版（内容は上と同一）
- `preview.html` — サンプルデータのfetchモック入りプレビュー（開発確認用。実データには繋がらない）
- `設定手順.md` — セットアップ・更新手順

## セットアップ

### 1. GAS側（データ処理API）

1. 対象スプレッドシート → 拡張機能 → Apps Script
2. `SeisanDashboard` という名前でスクリプトファイルを作成し、`gas/SeisanDashboard_コピー用.txt` の内容を貼り付け
3. `sd_authorize` を実行して権限を承認
4. デプロイ → ウェブアプリとして新規デプロイ
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
5. 発行された `.../exec` URLを控える

### 2. 画面側（GitHub Pages）

1. `index.html` 内の `GAS_API_URL` を、上記で発行されたURLに書き換える
2. GitHubにpush（このリポジトリはPublicで、Settings → Pages で `main` ブランチ・ルートを配信するよう設定済み）
3. `https://mirai-oss.github.io/seisan-dashboard/` が実際に配信するURL

### 3. 初回ログイン

自動生成される `権限_精算ダッシュボード` シートに、ランダムな初期パスワード付きで `honbu` アカウントが作成されます（Apps Scriptの実行ログに1回だけ表示）。ログイン後、⚙️設定タブから必ずパスワードを変更してください。

詳細は [設定手順.md](設定手順.md) を参照。
