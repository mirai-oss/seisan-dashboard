# 精算ダッシュボード

業務委託先の精算書を、入力チェック・PDF発行・メール送信・振込管理まで一気通貫で扱うWebダッシュボード（Google Apps Script製）。

- 対象スプレッドシート: `1GlJRMjKTMjqr22xo52xI3AdWJB2UZ_VlRDORqYOnXv4`（精算書 入力シート）
- 売上連携元: `1OuaAQBeXHxJZtDXEbQx-V7w56fCWW5jpDmZvBpkfIbQ`（【サーバー】ダッシュボード「分析_日別店舗」）
- 稼働: Google Apps Script Webアプリ（`?action=ping` でバージョン確認可）

> ⚠️ このリポジトリはコード内に委託先の個人情報・初期パスワード・スプレッドシートID等を含むため **Private** です。

## 解決する課題

1. 前月コピーで年月を変え忘れ、前月の精算書に混入する事故 → 店舗・対象月を先に選び、行ごとに月を書かない方式
2. 入力漏れが分かりにくい → 直近3ヶ月比で欠けている費目を自動検知
3. 精算計算がバラつく → DBを直接集計してPDFを自前生成（送付シートの数式に非依存）

## 主な機能

| 区分 | 機能 |
|---|---|
| 入力 | 明細入力（行ごとにファイル添付・自動リネーム）、明細修正（修正日記録・修正版は【再】付与）、先の月へ一括計上、現金売上の自動取込、定期費目の自動セット |
| 発行 | PDFプレビュー、精算書PDF発行（1ページ）、メール送信（その月の添付書類も同封）、再送信（件名・PDF名に【再送信】） |
| 管理 | 法人別の合計振込額・振込先・振込済みチェック、振込完了メール、店舗×月マトリクス、年間推移（売上/振込/N-style収益・CSVダウンロード） |
| 権限 | 本部（全機能）／委託先（担当店舗の閲覧のみ・N-style収益は非表示） |
| 自動 | 毎月1日 定期費目セット、毎月18日 振込期限リマインド（→ info@ns0314.com） |

## デプロイ / 更新

1. スプレッドシート → 拡張機能 → Apps Script
2. `SeisanDashboard` と `dashboard`（HTML）に各 `*_コピー用.txt` の内容を貼り付け
3. `sd_authorize` を実行して権限を承認
4. デプロイ → **デプロイを管理 → 編集 → 新バージョン → デプロイ**（実行ユーザー=自分、アクセス=Googleアカウント全員）
5. `?action=ping` で最新バージョンを確認

詳細は [設定手順.md](設定手順.md) を参照。
